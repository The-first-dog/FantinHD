# FantinHD — Site officiel

Site vitrine de **FantinHD**, développeur indépendant de jeux PC et mobile.

## Voir le site

- Dépôt : https://github.com/The-first-dog/FantinHD
- Adresse GitHub Pages (une fois activée) : https://the-first-dog.github.io/FantinHD/

## Fonctionnalités

- Accueil interactif sous forme de tableau de notes et de photographies.
- Présentations de **Farkle**, **3.2M**, **2:00:00** et d'un projet non annoncé.
- Filtrage **PC / Mobile**, fiches projet, section de présentation et liens.
- Mode de lumière jour/soir, affichage mobile, navigation clavier et prise en charge de la réduction des animations.
- **HTML, CSS et JavaScript** dans `index.html`. Aucune bibliothèque, aucun build ni clé API.

## Mettre en ligne

Dans le dépôt GitHub, aller dans **Settings → Pages** puis choisir :
- **Source** : Deploy from a branch
- **Branch** : main
- **Folder** : /(root)

Le site est également utilisable directement en ouvrant `index.html` dans un navigateur.

## Modifier les jeux

Le catalogue est rédigé dans le HTML. Les descriptions détaillées sont regroupées dans `gameData`, dans le script en bas de `index.html`. Les illustrations actuelles sont provisoires et dessinées en CSS ; les véritables captures et liens Steam / Google Play pourront être ajoutés ensuite.

## Direction artistique

Inspiration : [Teka Teki Studios](https://www.tekatekistudios.com/) — tableau rétro, fiches épinglées et objets interactifs. Le code, les éléments graphiques et le contenu de FantinHD sont originaux.
