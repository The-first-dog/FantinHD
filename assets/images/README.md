# Images des jeux

Chaque jeu a déjà un visuel « pixels de verre » dans [`visuels/`](visuels/), fait avec l'outil Voxel Type.

Pour afficher une **vraie capture** à la place, dépose-la **dans ce dossier** (`assets/images/`) avec exactement ce nom :

| Fichier | Jeu | Format conseillé |
| --- | --- | --- |
| `farkle.jpg` | Farkle | 1600 × 900 px (16:9) |
| `clean-glass.jpg` | Clean Glass | 1600 × 900 px (16:9) |
| `3-2m.jpg` | 3.2M | 1600 × 900 px (16:9) |
| `2-00-00.jpg` | 2:00:00 | 1600 × 900 px (16:9) |

Le site la détecte tout seul : rien à changer dans le code. Les noms sont en minuscules, avec des traits d'union. Exporte un vrai JPEG, ne renomme pas un PNG.

Sur GitHub : ouvre ce dossier, **Add file → Upload files**, puis **Commit changes**.
