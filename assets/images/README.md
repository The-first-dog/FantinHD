# Images du site FantinHD

Dépose tes images **dans ce dossier** : `assets/images/`

| Nom exact du fichier | Utilisation sur le site | Format conseillé |
| --- | --- | --- |
| `hero.jpg` | Image facultative derrière le grand logo en page d'accueil | 2560 × 1440 px, paysage 16:9 |
| `farkle.jpg` | Grande présentation du jeu Farkle | 1600 × 1000 px, paysage 16:10 |
| `clean-glass.jpg` | Grande présentation de Clean Glass | 1600 × 1000 px, paysage 16:10 |
| `3-2m.jpg` | Grande présentation de 3.2M | 1600 × 1000 px, paysage 16:10 |
| `2-00-00.jpg` | Grande présentation de 2:00:00 | 1600 × 1000 px, paysage 16:10 |

**Important :** ce sont des images de TES jeux, pas des images d'Embark Studios. Un montage de captures du jeu, une affiche officielle ou une capture représentative conviennent. Les images doivent être de véritables JPEG et porter exactement ces noms, en minuscules, avec les traits d'union indiqués. Ne renomme pas un PNG en JPG sans le convertir.

Le site est déjà configuré pour ces chemins. Dès que tu ajoutes un fichier, il apparaît sur le site sans modification du code. Si un fichier manque, un emplacement sobre avec son nom apparaît à la place. Le fond d'accueil reste noir sans `hero.jpg`.

Pour uploader via GitHub : ouvre ce dossier dans le dépôt, clique **Add file → Upload files**, ajoute tes images puis clique **Commit changes**.

Les projets confidentiels n'ont pas d'image publique par choix.
